> 2022 年台北市長選舉（蔣萬安、陳時中、黃珊珊三腳督）的民調分析專案，使用 **Vue 3 + D3.js v7** 製作三頁互動式 Dashboard。
> 這個專案描述的是「這一次選舉」民調與開票結果的差異，**不能**用來斷定某家民調機構有長期的系統性偏誤。

## 功能

### 三個頁面

| 頁面 | 議題 | 主要圖表 |
|---|---|---|
| 第 1 頁 | 民調預測準確度與「封關落差」分析 | 誤差散佈圖、分組長條圖、明細表 |
| 第 2 頁 | 行政區選票基本盤與民調空間分異的對比 | 民調 vs 實際雙地圖、堆疊長條圖、明細表 |
| 第 3 頁 | 選民結構交叉分析與「潛在動搖票」定位 | 100% 堆疊長條圖、熱力圖、潛在動搖票長條圖、趨勢折線圖 |

**第 1 頁**
- 比較 7 家封關前最後一次民調（台灣民意基金會、中廣蓋洛普、聯合報、TVBS、自由時報、CNEWS 匯流、三立新聞）與實際得票率的誤差。
- 摘要卡片：誤差最小與最大的機構、各候選人的平均偏差。
- 可切換口徑：「排除未表態（三人合計＝100%）」或「原始民調數字」。

**第 2 頁**
- 雙地圖並列「民調推估」與「實際開票」，可切換「各區領先者」或單一候選人得票率；單一候選人模式兩張圖共用同一個色階。
- 民調領先者與實際不同的區用橘色虛線框標出。
- 明細表列出各區樣本數、95% 信賴區間、民調與實際差距。
- 預設為示意方塊圖；放入 GeoJSON 會自動改畫真實行政區邊界。

**第 3 頁**
- 年齡、教育程度、政黨傾向、性別的交叉分析（堆疊圖與熱力圖）。
- 潛在動搖票：各族群占全體「未表態者」的比例。
- TVBS 年齡層趨勢圖：圖例可點擊開關，預設顯示 4 條線。

### 共通功能
- header 分頁連結、footer（`1151VIS-G03`）、hash 路由。
- 每頁最下方有「備忘區」：圖表怎麼看、注意事項。
- 每個圖形元素有 tooltip；重要數字直接印在圖上。
- 淺色／深色模式自動切換；版面可隨螢幕寬度調整。
- 候選人色彩：蔣萬安（國民黨）藍、陳時中（民進黨）綠、黃珊珊（無黨籍）黃；誤差方向用橘色與另一組藍色，避免與候選人混淆。


## 資料整理與製作過程

### 1. 選題與資料蒐集
- 選擇 2022 年台北市長選舉：該屆已有完整開票結果，可以與封關前民調做比較；2026 年的選舉尚未開票，無法計算誤差。
- 封關前民調取自媒體彙整報導；各行政區民調與交叉分析取自台灣民意基金會的記者會書面資料；各區開票取自 ETtoday 選舉專區（中選會資料）；年齡層趨勢取自 TVBS 民調中心報告與新聞報導。

### 2. 資料整理規則
- **排除未表態：** 把蔣、陳、黃三人的民調數字各自除以三人合計，再乘 100，使三人合計為 100%，才能和開票得票率比較。實際得票率以同樣的方法換算（三人合計 99.36%，其餘為小候選人）。
- **誤差：** 民調（換算後）減實際得票率，單位為百分點（pp）。
- **平均絕對誤差（MAE）：** 三位候選人誤差絕對值的平均，用來排序各家民調。
- **蔣陳差距誤差：** 民調的蔣−陳差距，減去實際差距（10.36 pp）。
- **各區民調：** 同樣換算成三人合計 100%；95% 信賴區間用 `1.96 × √(0.25 / n)`（p = 0.5 的保守估計）。
- **未表態：** 「還不能決定」與「不知道」合併為「未表態」。
- **潛在動搖票：** 某族群佔全體未表態者的比例 ＝ 該族群未表態比例 × 樣本數 ÷（全體未表態比例 × 全體樣本數）。
- **趨勢圖缺值：** 缺值處不內插，線條會斷開（目前四個時點的資料已補齊）。

### 3. 圖表設計
- 精確比較用位置與長度；色相保留給候選人身分，同一候選人的數量差異用不透明度表示；重要數字直接印在圖上。
- 小樣本（n < 50）以「＊」標記。
- 詳細的通道選擇與理由見專案報告的〈Visual Encoding：資料到視覺通道〉。

### 4. 實作
- Vue 3（`<script setup>`）、vue-router（hash 模式）、D3 v7、Vite。
- D3 負責繪製 SVG，Vue 負責狀態與切換；資料集中在 `src/data/`，統計計算集中在 `src/utils/`。

### 5. 驗算與品質檢查
- 12 個行政區的得票數加總與全市得票完全吻合：蔣萬安 575,590、陳時中 434,558、黃珊珊 342,141。
- 各區民調（含未決定與不知道）每列加總為 100%。
- 各項數字與備忘區、解讀文字逐項對照資料。

### 6. 已知限制
- 封關民調的數字取自媒體彙整，未逐一核對各家原始報告。
- 各行政區民調與族群交叉分析都來自**單一機構**（台灣民意基金會），每區樣本僅 51–119 人，誤差很大。
- 趨勢圖的 8/26、10/2 取自 TVBS 原始報告；11/1、11/15 取自新聞報導，日期為報導日期。
- 地圖預設是依方位排列的示意方塊圖，不是真實邊界。
- 圖表之間是「切換式連動」，尚未支援跨圖刷選。
- 單次選舉的比較，不能推論機構的長期偏誤。
